## 1. Problem statement

A0.4–A0.6 closed **release admission** and **bootstrap containment**. v5/v5.1 prove the remaining blocker is **release execution terminality**:

```text
MEDIA_RELEASE_REQUESTED
    ↓
MEDIA_RELEASE_SCHEDULED
    ↓
RELEASE_ENTER (M02/M04)  OR  edge task never START (M03 SRD hang)
    ↓
✗ MEDIA_RELEASED
✗ MEDIA_RELEASE_FAILED
    ↓
HangupMediaBarrier pending forever
    ↓
HANGUP_BOOTSTRAP_DEFERRED loop (correct) but UX "hangup dead"
```

> **An admitted release transaction MUST NOT remain in RUNNING indefinitely because a prior native/edge operation may never complete.**

This is **not** the same problem as A0.5 bootstrap bypass. Fixing bootstrap again will not resolve it.

### Architectural progress (v5 → v5.1)

Failure state **contracted** from silent bootstrap loop to explicit pending release:

```text
old:  release stuck + fake Group bootstrap + ownership contention + misleading logs
now:  release stuck + bootstrap correctly deferred + ownership retained + explicit DEFERRED
```

v5.1 "more dead" UX is **not regression** — it is a healthier failure posture pending A0.7.

## 3. Normative invariants

### A0.7.1 — Terminal fact required

> **Every admitted release transaction MUST reach exactly one terminal fact.**

```text
RELEASE_REQUESTED / SCHEDULED / EXECUTING  →  RUNNING
RUNNING  →  RELEASED  |  FAILED
```

Forbidden indefinitely:

```text
RELEASE_RUNNING with no terminal fact
```

### A0.7.2 — Terminal failure ≠ ownership release

> **Terminal failure MUST NOT imply engine ownership release.**

```text
MEDIA_RELEASE_FAILED
    → ownership RETAINED (EngineOwnershipGate FAILED state)
    → NO happy-path GROUP acquire / MEDIA_PROVISION_REQUESTED
```

Aligns with [hangup gate §3.1](./media-engine-ownership-hangup-gate.md#31-failed--ownership-released-normative) and [boundary §4.2](./coordinator-media-execution-boundary.md#42--media_release_failed-recovery-gate).

### A0.7.3 — Preemption ≠ native kill

> **Preemption MUST NOT kill, interrupt, or synchronously join native execution.**

Preemption means:

```text
Coordinator emits terminal failure fact
    without waiting for hung edge/native task completion
```

Preemption does **not** mean:

```text
force-stop native call
sync factory.release() on coordinator thread
Thread.interrupt on edge executor
```

Violates A0.2/A0.3 and reopens D-β/γ risk.

### A0.7.4 — One-shot terminalization; late completion absorbed

> **Terminalization is one-shot. Late completion MUST NOT reopen ownership or handoff.**

```text
RUNNING
  ├── RELEASED      (first terminal wins)
  └── FAILED        (first terminal wins)

Late path after FAILED:

  edge/native completes
      ↓
  MEDIA_RELEASE_LATE_COMPLETION   (telemetry only)
      ↓
  NO ownership NONE
  NO GROUP handoff
  NO barrier reopen as success
```

**Terminal latch:** per `moduleId` release transaction record holds terminal state; subsequent `MEDIA_RELEASED` callbacks are **ignored for ownership** and logged as late completion.

Without A0.7.4, watchdog creates:

```text
FAILED → ownership retained → late RELEASED → accidental NONE → race
```

### A0.7.5 — Barrier may terminalize on failure

> **Hangup barrier MAY complete with `allSucceeded=false`, but retained ownership continues to block GROUP handoff.**

```text
barrier terminal
    =
all release transactions have an outcome (RELEASED or FAILED)

barrier terminal
    ≠
engine released on all modules

allSucceeded=false
    → skip happy-path releaseConferenceChannelForGroupPtt / GROUP bootstrap
    → ownership RETAINED on failed modules blocks acquire
```

Aligns with [hangup gate §6.1](./media-engine-ownership-hangup-gate.md#61-partial-module-barrier).

### A0.7.6 — Watchdog on coordinator turn

> **Watchdog MUST execute on a Coordinator turn and MUST NOT wait for Media Runtime.**

```text
ALLOWED:
  schedule coordinator runnable
  observe facts / timers / hung-native signals
  emit MEDIA_RELEASE_FAILED
  engineOwnershipGate.markFailed(moduleId)
  hangupBarrier.onModuleTerminal(moduleId, success=false)

FORBIDDEN:
  coordinator thread join edge executor
  sync wait on factory.release / PC close
  completion callback → same-tick media invoke (A0.2)
```

## 4. Release transaction state machine

Per `moduleId` (conference hangup barrier set):

```text
                    admitConferenceRelease()
                            │
                            ▼
                      ┌───────────┐
                      │  RUNNING  │
                      └─────┬─────┘
            ┌───────────────┼───────────────┐
            │                               │
     normal edge path                  watchdog path
            │                               │
            ▼                               ▼
     MEDIA_RELEASED              MEDIA_RELEASE_FAILED
     origin=mediaSessionClose    cause=RELEASE_PREEMPTED_HUNG_RUNTIME
            │                               │
            ▼                               ▼
     ownership NONE                 ownership RETAINED
     barrier success=true           barrier success=false (if any FAILED)
```

### Initial A0.7a failure fact (single terminal failure)

Do **not** split `FAILED` vs `UNRESOLVED` in A0.7a implementation:

```text
MEDIA_RELEASE_FAILED module=Mxx cause=RELEASE_PREEMPTED_HUNG_RUNTIME
```

Future waves MAY distinguish `operation failed` vs `outcome unknown` if field requires it.

## 5. Ownership semantics (normative mapping)

| Terminal fact | Ownership | GROUP happy-path |
|---------------|-----------|------------------|
| `MEDIA_RELEASED` | `NONE` | MAY proceed after barrier + A0.1 turn separation |
| `MEDIA_RELEASE_FAILED` | `RETAINED` / `FAILED` gate state | **MUST NOT** acquire |
| `MEDIA_RELEASE_LATE_COMPLETION` | **unchanged** | **MUST NOT** handoff |

```text
RELEASED  →  ownership = NONE
FAILED    →  ownership = RETAINED  →  no happy-path GROUP acquire
```

## 6. Late completion contract

Sequence that MUST be safe after A0.7a:

```text
T0  release submitted (RUNNING)
T1  native/edge hang
T2  coordinator watchdog turn
T3  MEDIA_RELEASE_FAILED(cause=RELEASE_PREEMPTED_HUNG_RUNTIME)
T4  ownership RETAINED; barrier module terminal(success=false)
T5  original edge task completes
T6  MEDIA_RELEASE_LATE_COMPLETION
T7  ownership still RETAINED; NO GROUP handoff
```

Implementation requirement:

```text
onMediaReleased(moduleId) {
  if (releaseTxn.alreadyTerminal(FAILED)) {
    log MEDIA_RELEASE_LATE_COMPLETION
    return   // no gate.markReleased / no NONE
  }
  ... normal RELEASED path ...
}
```

## 7. Watchdog preemption model (A0.7a design)

**Purpose:** Release transaction terminalization only — **not** physical runtime cleanup (A0.7b).

### Trigger conditions (any MAY fire watchdog on coordinator turn)

```text
1. SCHEDULED/REQUESTED but no EDGE_TASK_START(mediaSessionClose) within T_start
2. RELEASE_ENTER but no terminal fact within T_complete
3. Session TERMINATED + SRD_WATCHDOG_GAP / NATIVE_DOMAIN_EXECUTION_ACTIVE on module
4. Hangup barrier module still RUNNING while coordinator hangup turn has ended
```

Exact `T_start` / `T_complete` are **implementation constants** in A0.7a — not product SLA. They exist only to bound **control-plane** RUNNING, not native lifetime.

### Watchdog action (allowed)

```text
emit MEDIA_RELEASE_FAILED(cause=RELEASE_PREEMPTED_HUNG_RUNTIME)
engineOwnershipGate.markFailed(moduleId)
hangupBarrier.onModuleTerminal(moduleId, success=false)
mark releaseTxn terminal(FAILED)   // latch
ignore/idempotent subsequent edge completions for this txn
```

### Watchup action (forbidden)

```text
kill native · interrupt edge · sync release on coordinator
auto GROUP bootstrap because barrier "finished"
FAILED → NONE without new explicit recovery ADR
```

### Shared-factory note (v5 evidence)

M02/M04 `RELEASE_ENTER` without `MEDIA_RELEASED` while M03 SRD hung suggests **domain-level** blocking, not queue-only. A0.7a **minimum** implements per-module watchdog in barrier set; correlated factory-domain fan-out MAY follow in A0.7a follow-up **without** native kill.

## 8. Hangup barrier interaction

Existing `HangupMediaBarrier` API is sufficient:

```text
onModuleTerminal(moduleId, success=true)   → RELEASED path
onModuleTerminal(moduleId, success=false)  → FAILED path
pending empty → onComplete(allSucceeded)
```

A0.7a MUST ensure **every barrier module** reaches `onModuleTerminal` — never leave module in pending forever.

Callback policy (unchanged from hangup gate §6.1):

```text
allSucceeded=true   → releaseConferenceChannelForGroupPtt → GROUP handoff allowed
allSucceeded=false  → log; NO happy-path GROUP bootstrap
```

```text
REQUESTED → SCHEDULED → RELEASED → ownership NONE → barrier success → GROUP handoff
```
